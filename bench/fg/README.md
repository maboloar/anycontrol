# 정지 배경 모델 (색 + Depth Anything) 벤치

"배경은 움직이지 않고 물체·손·팔만 움직인다"를 추적 신호로 쓰는 `tracking/scene.py`(SceneModel)를 기존 트래커와 비교한다.

## 무엇을 했나
- **색 배경**: 픽셀마다 Lab 평균·분산(폭 320 내부 해상도). 전역 밝기 보정, 카메라 미세 이동 보정(위상 상관, 움직이는 물체는 가림, 배경 차이가 실제로 줄 때만 적용), 그림자는 약한 전경.
- **선택적 학습**: 추적 중인 물체(amodal + 여유)와 손 영역은 배경으로 배우지 않는다. 등록 때 물체 밑은 '모름'으로 두고, 물체가 떠나면 채운다(평균이 수렴했을 때만 '앎' — 유령 방지).
- **깊이 배경 (Depth Anything V2 Small)**: 6Hz 비동기(앱은 `DepthService`, 평가는 sim 지연). 프레임마다 `d ≈ a·배경 + b`로 정렬하고 '가까워짐'만 전경 근거로 쓴다.
  색이 '배경'이라 해도 깊이가 솟았으면 전경(같은 색 물체), 그림자·약한 색 변화(반사)는 깊이가 그대로면 배경. 납작한 물체(종이·카드)는 깊이로 지우지 않는다.
- **안전장치**: 배경의 20% 이상이 한꺼번에 바뀌면(카메라 이동·조명 급변) 그 프레임은 무효(신호 없음 = 기존 동작). 0.6초 이어지면 다시 배운다.

추적기 연동 (`vi_tracker.py`, 펜은 제외)
| 위치 | 쓰임 |
|---|---|
| 첫 분할(등록) `register.choose_candidate` | 후보들의 공통 영역이 '새로 나타난 것'이면, 확실한 배경(책상·벽)을 많이 덮은 후보를 덜 고른다 |
| Tier 0 영역 마스크 `refine_mask` | 로그 오즈를 색·형태 사전에 더하고, 확실한 배경(< −2.5)은 사전 안쪽이라도 뺀다 |
| 상태 판정 | 예측 자리가 '아는 배경 그대로'면 물체가 없다(화면 이탈·배경에 붙은 점 추적). 배경과 뚜렷이 달라 보이는 물체만 (유리·저대비 제외), 주변에 전경 덩어리가 있으면 보류 |
| 점 재표본 | 확실한 배경 위에는 점을 뿌리지 않는다 |
| 주기적 재분할(비동기) `refresh.choose_mask` | 배경을 25% 넘게 덮은 후보를 버리고 배경으로 번진 부분을 자른다 |
| Tier 1 마스크 잘라내기 `scene_t1` | 구현했지만 합성 tune 0.907→0.900 으로 손해라 **기본 끔** |
| 앱 파이프라인 | 물체가 없어도 `observe()`로 빈 책상을 배운다. 깊이는 공유 `DepthService` 로 |

펜은 쓰지 않는다: 접촉 F1 이 떨어졌다 (pen_test 0.924→0.901/0.789, IMG_0002 0.774→0.647/0.611; 색/색+깊이). 지금 펜은 기존과 같은 점수.

- 합성 영상의 물체는 책상에 붙인 스티커라 깊이로 솟아 보이지 않는다 → 합성에서 깊이 효과는 측정되지 않는다(약간 손해). 실영상에서는 깊이가 중심 오차를 더 줄였다.
- 처리 시간은 배경 갱신 약 2.6ms + 연동 비용. 깊이 추론(약 36ms)은 별도 스레드.
- 정답: `gt/test.json`(지갑 44 키프레임), `gt/img_0002.json`(펜 65 키프레임) — `make_gt.py`(공식 EfficientTAM 비디오 예측기 오프라인 전파) + 그림 검수. 펜 정답은 앱 펜 등록(손가락 아래 조각)과 맞지 않아 접촉 F1 로만 평가했다.

## 실행
```bash
export PYTHONPATH=backend/src:third_party/EfficientTAM
backend/.venv/bin/python -m vision_input.eval run --tracker vi_noscene --split tune     # vi, vi_fgd, vi_fg_t1
backend/.venv/bin/python -m vision_input.eval run --tracker vi_fgd --video samples/test.mov --gt bench/fg/gt/test.json
PEN_TRACKER=vi_fgd backend/.venv/bin/python bench/pen/track_cache.py bench/pen/configs/pen_test.json --step 2   # 펜 벤치에 트래커 선택
```

## 끄기·조절
`TrackerConfig.scene = SceneConfig(enabled=False)` 면 이전과 같다. 깊이만 끄려면 `SceneConfig(depth=False)`. 가중치 `scene_w`(0.6), '없음' 문턱 `scene_absent`(−1.2).
개발자 화면의 물체 기억 보기(`GET /api/objects/{id}/memory`)에 `scene`(유효 여부, 바뀐 비율, 카메라 이동, 깊이 횟수, 물체 대비)가 나온다.

## 한계
- 카메라가 크게 움직이면 꺼진다(그동안은 기존 동작). 손에 든 카메라에서는 이득이 적을 수 있다.
- 물체가 처음부터 책상에 있으면 그 밑 배경은 물체가 움직일 때까지 '모름'이다.
- 실영상 정답은 한 영상(지갑)뿐이다. 실제 카메라에서의 체감 확인이 필요하다.
