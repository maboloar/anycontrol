# AnyControl v1.8.0

#### 2026 고려대학교 × AWS AI INNOVATORS CHALLENGE 출품작

*카메라 한 대면 충분합니다. 책상 위 컵도, 평범한 펜도, 맨손도 마우스가 되고, 키보드가 되고, 게임패드가 됩니다. 여러 물체를 동시에 알아보고, 가려져도 기억해서 다시 찾아냅니다. 모든 처리는 실시간·온디바이스로 작동해 인터넷 연결 없이도 가능합니다.*

카메라로 물체와 손의 움직임을 추적해 마우스·키보드 입력으로 사용하는 macOS용 로컬 웹앱입니다. 물체 매핑, 맨손 마우스, 펜·검지 그리기와 연습용 데모를 제공합니다.

## 다운로드 및 설치

> 이 소스 트리의 버전은 v1.8.0입니다. v1.8.0 배포 실행파일은 `releases/`에 빌드되어 있으며 GitHub Release 업로드는 별도로 진행합니다. 실제 다운로드 시 공개된 릴리스를 확인하세요.

1. [GitHub Releases](https://github.com/maboloar/anycontrol/releases)에서 `AnyControl-v1.8.0-macOS.command`를 다운로드합니다. 삭제용 `AnyControl-Uninstall-v1.8.0-macOS.command`도 함께 받아 두세요. **Source code 압축 파일은 일반 사용자용 설치 파일이 아닙니다.**
2. 실행용 `.command` 파일을 더블클릭합니다. **보안 차단 또는 “적절한 접근 권한이 없기 때문에…” 오류가 나오면 [처음 실행 시 보안·실행 권한 안내](#first-launch-permissions)를 먼저 따라 주세요.** 터미널이 열리면 설치가 진행됩니다. 최초 설치는 인터넷 속도에 따라 수 분 걸릴 수 있습니다.
3. 카메라 권한 요청을 허용합니다. 설치가 끝나면 브라우저에서 AnyControl이 자동으로 열립니다.
4. 화면의 튜토리얼을 따라 카메라를 선택하고 물체나 손 입력을 설정합니다. 실제 Mac의 마우스·키보드를 제어하려면 손쉬운 사용 권한을 허용하고 앱에서 실제 입력을 켭니다.

**의존성 자동 설치:** `.command` 실행파일을 실행하면 필요한 Python과 모든 라이브러리(requirements)가 자동으로 설치됩니다. 따로 미리 설치할 것은 없습니다.

기본 설치 위치는 `~/Library/Application Support/AnyControl/`입니다. Python, 라이브러리, 프로그램과 로그가 이 폴더에 설치됩니다. 저장한 매핑은 `profiles/`에 보관됩니다. 실행파일에는 추적 모델과 웹 화면이 포함되어 있습니다.

처음 실행할 때 **보안 차단 → 실행 권한 오류**가 차례대로 나타날 수 있습니다. 아래 [Troubleshooting의 처음 실행 안내](#first-launch-permissions)에서 두 단계를 순서대로 해결하세요.

## 요구사항

### 필수 실행 요구사항

- **OS·기기:** macOS 14 이상, Apple Silicon(M1 이상)
- **메모리:** 8GB 이상, 16GB 권장
- **최초 설치:** 디스크 여유 공간 4GB 이상 및 인터넷 필요
- **카메라:** 필수 — iPhone 연속성 카메라 USB 연결 권장
- **권한:** 카메라 필수, 실제 OS 입력 기능 사용 시 손쉬운 사용 권한 필요
- **설치:** `.command` 실행 시 Python과 라이브러리 자동 설치, 사전 설치 불필요
- **오프라인 실행:** 최초 설치 후 인터넷 없이 사용 가능

### 개발 시 추가 요구사항

- **Python:** 3.12 이상, 3.13 권장
- **Node.js:** 빌드 22.12 이상 / 테스트 포함 22.22.2 이상 또는 24.15 이상
- **의존성:** [requirements-macos-arm64.lock](packaging/requirements-macos-arm64.lock) 기준 설치

소스 실행, 테스트와 배포 파일 빌드는 [개발 안내](DEVELOPMENT.md)를 참고하세요. 일반 사용자는 Node.js, Homebrew, Xcode를 설치할 필요가 없습니다.

## iPhone 연결 — 연속성 카메라 (Continuity Camera)

iPhone을 Mac의 웹캠으로 연결하는 Apple 기능입니다. **USB 유선 연결을 권장합니다.** Apple의 [연속성 카메라 공식 안내](https://support.apple.com/ko-kr/102546)에 따른 조건입니다.

- iPhone XR 이후 모델, iOS 16 이상. AnyControl의 Mac 요구사항은 macOS 14 이상입니다.
- 두 기기에서 **이중 인증을 사용하는 같은 Apple 계정**에 로그인해야 합니다.
- iPhone의 **설정 → 일반 → AirPlay 및 연속성**(또는 **AirPlay 및 Handoff**)에서 **연속성 카메라**를 켭니다.
- 두 기기를 가까이 두고 Wi-Fi와 Bluetooth를 켭니다. iPhone의 개인용 핫스팟과 Mac의 인터넷 공유는 끕니다.
- USB 연결 시 iPhone에서 **이 컴퓨터를 신뢰**하도록 설정합니다. 무선 사용 시 Mac에서 AirPlay와 Sidecar를 사용하지 않습니다.

iPhone을 USB로 연결하고 잠근 뒤, 거치대에 고정해 후면 카메라가 추적할 물체·손을 향하도록 놓습니다. AnyControl의 **카메라 → 장치 새로고침**을 누르고 iPhone을 선택합니다. 연결된 카메라가 자동 선택될 수도 있습니다. Desk View는 지원되는 iPhone에서 사용할 수 있으며 기기별 조건은 Apple 공식 안내를 참고하세요.

## 사용 및 종료

- **물체 마우스:** 카메라에서 물체를 드래그해 등록하고 마우스 패널에서 대상을 고릅니다. 기본은 좌우 이동 → 커서 좌우, 카메라 쪽/반대쪽 이동 → 커서 위아래이며 앞뒤 신호는 물체 크기 변화입니다. 깊이 모델은 고급 설정에서 고를 수 있습니다. **물체 마우스는 커서 이동만 하며 손 추적을 쓰지 않습니다**(손으로 클릭하기·한 손 하이브리드는 삭제). 펜 물체는 책상에 닿으면 클릭합니다(Beta).
- **맨손 마우스:** 영상 XY 위치로 이동합니다. 엄지+검지 집게는 왼쪽 누름·드래그, 엄지+중지는 오른쪽 누름입니다. 검지·중지만 펴고 엄지·약지·새끼를 접은 채 위아래로 움직이면 스크롤합니다.
- **빠른 자동 보정:** 대상 등록/선택 후 실행합니다. 기본은 잠깐 정지 → 현재 위치에서 좌우 왕복 → 앞뒤 또는 영상 위아래 왕복입니다. 매번 중앙으로 원위치할 필요가 없습니다. 맨손 마우스는 클릭·스크롤 보정을 선택할 수 있고(물체 마우스는 이동만 보정), 펜은 접촉/들기 단계를 따로 진행합니다. 적용 전 결과를 확인할 수 있고 취소하면 기존 설정을 유지합니다.
- **맨손 카드·패치 잭:** 물체 패널의 맨손 매핑 스위치는 맨손 잭에만 적용합니다. 물체 터치·맨손 마우스·그리기는 각자 설정을 따릅니다. 맨손 잭도 손바닥 좌우(X)·상하(Y)를 연속 입력으로 연결할 수 있고, 버튼에는 엄지+검지/엄지+중지 집게를 씁니다. 케이블에서 입력 동작·감도·방향을 바꿉니다.
- **물체 터치:** 인식된 손이 물체의 원래 마스크 안을 실제로 가리는 외형 증거를 연속 두 프레임 확인합니다. 뒤쪽 손이 바꾼 배경, 손가락 사이 빈 공간, 물체의 구멍, 표면 무늬가 보존된 그림자·밝기 변화는 접촉 증거에서 제외합니다. 손끝·손바닥·손가락 옆면을 지원하고 기본 민감도는 70%입니다. 처음에는 손을 잠깐 물체에서 떼어 기준 모습을 잡아 주세요. 물체 마스크가 없거나 손·물체가 사라지면 입력을 해제하며, 맨손 매핑 스위치와 관계없이 동작합니다. 공중에서 물체를 완전히 가리는 동작과 실제 접촉, 물체와 같은 색의 손/장갑과 그림자는 단일 영상만으로 완전히 구분할 수 없어 애매한 증거는 누르지 않는 쪽으로 처리합니다. 손 인식이 잠깐(0.6초 이내) 끊겨도 손가락이 그대로면 터치를 유지합니다. 카메라 화면의 게이지가 찼는데 터치가 아니면 그 이유(손이 인식되지 않음·조명 변화·물체 무늬가 그대로 보임 등)를 노란 글씨로 보여 줍니다. 진단 표시는 고급 모드의 ‘터치 감지 표시’로 켭니다.
- **매핑·프로필:** 위·아래의 **매핑 추가**와 연결 편집은 같은 편집기를 사용합니다. 입력 종류·물체/맨손·축/제스처·출력을 고르고 ‘추가’를 누르면 잭·행·케이블이 함께 표시됩니다. 맨손은 손바닥 영상 X/Y와 엄지+검지/중지 집게 4가지를 양쪽에서 똑같이 선택할 수 있습니다. 민감도와 세부 설정(범위·반전·데드존·곡선·누름/뗌·부드럽게·놓쳤을 때)도 서로 반영됩니다. 설명을 붙여 추가한 사용자 잭은 전체 초기화 후에도 보존하며 선택한 맨손 동작·변환 설정으로 다시 연결할 수 있습니다. 잭을 끌거나 양쪽을 한 번씩 눌러 연결하고, 케이블 왼쪽 클릭으로 입력·감도·방향을 편집하거나 **매핑 해제** 버튼·케이블 휠 클릭으로 해제합니다. 물체 이름을 바꿔도 현재 연결을 유지합니다. 매핑 전체 초기화는 두 번 눌러 실행하며 DJ 연결처럼 매핑 패널에 보이지 않는 연결까지 모두 지웁니다. 물체와 저장 프로필은 보존합니다.
- **추적 보호:** 튐 억제는 기본 켬입니다. 물체가 겹치면 ‘겹침’을 표시하고, 상대 모습을 잘못 배우지 않도록 외형 학습과 재분할 보정을 잠시 보류합니다. 완전 가림과 닮은 물체는 여전히 어려울 수 있습니다.
- **연습 데모:** 레이싱·퐁·에어 하키·과일 받기·좀비 서바이벌·DJ 셋·가상 데스크톱·펜/맨손 그리기를 제공합니다. 데모는 모든 패널 아래 전체 너비 한 줄에 표시되고, 모든 게임의 기본 인원은 1P입니다. `Space`로 게임을 일시정지합니다. 가상 데스크톱은 맨손·물체 마우스를 켜야 쓸 수 있습니다(꺼져 있으면 안내와 [마우스 패널로 이동] 버튼). DJ 연결은 DJ 패널의 패치 베이에서만 다루며, DJ 셋을 보는 동안 매핑 패널은 게임 잭과 DJ 연결을 숨깁니다. DJ 패치 베이는 셋 위에 있고, 124 BPM 멜로딕 하우스 루프와 클랩 효과음을 사용합니다. 펜 기능은 **Beta**입니다.
- **화면·성능:** 기본 모드에도 입력 좌우 반전과 성능 패널이 있습니다. 영상 좌우 반전은 표시만, 전체 입력 좌우 반전은 조작 방향을 바꿉니다. 제목 줄을 끌어 패널을 옮기고 ‘배치 초기화’로 복원할 수 있습니다.
- **안내·유휴 화면:** 제목 바로 오른쪽의 **안내**를 누르면 따라 하기 튜토리얼을 엽니다(물체 등록 → 기능 연결 → 게임 고르기 → 자동 매핑 → 직접 해 보기, 각 단계를 해내면 초록색으로 바뀌고 자동으로 넘어가며 [건너뛰기] 가능). 고급 모드에서는 제목 아래에 `고급 모드 · backend v1.8.0` 순으로 작게 표시합니다. 키보드·마우스 입력이 20초 없으면 안내 옆에 큰 보라색 안내 문구가 나타나고 상단바 전체가 보라색으로 더 강하게 빛납니다. 문구가 보일 때만 상단바가 고정되며, 입력 뒤 10초 동안 문구를 읽을 시간을 준 뒤 함께 해제합니다. 시연 화면에서 복귀하면 문구가 즉시 나타납니다. 문구 오른쪽 ×로 닫으면 다음 시연 화면 전까지(새로고침 전까지) 다시 뜨지 않습니다. 실제 OS 입력 중에는 기존 정지 안내 색상을 우선합니다.
- **게임 조작:** 모든 게임의 **시작/계속·처음부터**는 자동 매핑 상자 오른쪽의 큰 버튼입니다. 자동 매핑 옆 **민감도**는 현재 게임의 좌우·앞뒤/상하 축(2인일 때 양쪽 컨트롤러)을 함께 조절합니다. 매핑 패널의 같은 범위를 변경하므로 서로 반영되며 축별 비율과 반전은 유지합니다. 축별 값이 다르면 ‘축별 설정’으로 표시하고 평균 배율을 보여 줍니다. 에어 하키 1인은 **AI 난이도: 쉬움·보통·어려움**을 선택할 수 있고 기본 보통은 이전보다 조금 쉽습니다.
- **모든 세팅 초기화:** 어두운 빨간 버튼을 두 번 누릅니다. 등록 물체·현재 매핑·입력/추적/보정/화면 설정을 초기화하고 실제 출력도 끕니다. 저장 프로필·사용자 정의 잭·현재 카메라 연결/해상도/FPS는 보존합니다. 무입력 시연 화면 기본 대기는 120초이며 진입 때도 배치·패널 크기를 포함한 같은 초기화를 실행합니다.
- **긴급 정지:** `Esc`로 입력 출력을 멈추고 누른 키·버튼을 해제합니다. 실제 Mac 제어는 별도 손쉬운 사용 권한과 출력 활성화가 필요합니다.

**장시간 실행:** 하루 6시간 이상 켜 두는 부스 운영을 기준으로 손 인식 메모리 누수와 추적 크기 발산에 따른 메모리 폭증을 고쳤습니다(녹화 영상 10분 측정 시 약 1.5GB에서 평탄).

**종료는 브라우저의 AnyControl 탭을 닫으면 됩니다.** 여러 탭을 열었다면 모두 닫으세요. 약 5초 후 서버와 터미널에서 실행 중인 프로그램이 자동 종료됩니다. 터미널 창 자체가 남는 경우에는 닫아도 됩니다(창 자동 닫기는 Terminal 설정에 따릅니다).

다시 사용하려면 같은 실행용 `.command` 파일을 더블클릭합니다. 업데이트할 때는 기존 앱을 종료하고 새 릴리스의 실행파일을 열면 됩니다. 저장한 프로필은 유지됩니다.

### 게임 자동 매핑

1. 사용할 물체를 영상에서 등록하고, 게임의 1인/2인 모드를 고릅니다(좀비는 1인).
2. 게임 위에서 컨트롤러와 조작법을 고른 뒤 **자동 매핑**을 누릅니다. 레이싱은 좌우 이동/기울기, 퐁·과일·좀비·하키는 바닥에서 크기/앞뒤로 상하 조작 또는 들고 영상 위아래로 조작을 고릅니다. 맨손은 영상 XY를 사용합니다.
3. 자동 매핑은 매핑 패널에 가상 게임패드 축 잭·케이블을 실제로 만듭니다. 게임 예시는 패드 축 연결을 교체하여 이전 게임의 축·트리거가 합쳐지지 않게 하고, 키·마우스·버튼·DJ 연결은 유지합니다. 2인 모드에는 서로 다른 컨트롤러가 필요합니다.
4. 연결 없이 시작하면 자동 매핑 안내를 표시합니다. 자동 매핑 대신 매핑 패널에서 게임 잭을 수동 연결해도 됩니다. ‘게임 잭 보기’에서 게임을 고르면 해당 잭을 볼 수 있습니다.
5. 게임 도중에도 매핑 패널에서 물체/맨손·입력 축·감도·방향·사용 여부를 바꿀 수 있습니다. 변경은 기존 자동 저장 경로(약 0.3초 후 전송)로 반영됩니다. 게임과 가상 게임패드 표시는 같은 스틱·트리거 값을 사용합니다. 물체 좌표나 마우스 커서를 대신 읽지 않습니다. 앱 안 편집은 게임을 멈추지 않고, 창을 떠나거나 Esc를 누르면 멈춥니다.

**에어 하키:** 왼쪽 1P와 오른쪽 컴퓨터/2P가 원형 말렛으로 퍽을 쳐 상대 골대에 넣습니다. 물체를 바닥에 두고 좌우·앞뒤로 조작하며, 각자 자기 진영 안에서 움직입니다. 빠르게 밀면 타격에 힘이 실리고 7골을 먼저 넣으면 이깁니다. 1P WASD, 2P 방향키도 연결 후 보조 조작으로 쓸 수 있습니다.

모든 게임은 화면 폭·디스플레이 배율에 맞춰 캔버스의 실제 픽셀 수를 늘립니다. 크기 변경과 Retina 화면에서도 논리 좌표·충돌 판정은 같고 선과 글자가 선명해집니다. 성능 보호를 위해 최대 약 400만 픽셀로 제한합니다. DJ는 자체 패치 베이와 화면 조작을 유지합니다.

## 삭제

`AnyControl-Uninstall-v1.8.0-macOS.command`를 더블클릭하고 터미널 안내를 따라 삭제합니다. 실행 중인 AnyControl은 종료 여부를 묻고, 저장한 프로필은 별도로 삭제할지 묻습니다(기본은 보존).

설치된 프로그램·Python·라이브러리·캐시·로그가 제거됩니다. 다운로드한 `.command` 파일 자체와 macOS 권한 목록은 남으므로 필요하면 직접 정리하세요.

<a id="first-launch-permissions"></a>

### 처음 실행 시: 보안 차단 및 실행 권한

다운로드한 `.command`를 처음 열면 아래 두 오류가 **차례대로 나타날 수 있습니다**. 보안 차단을 허용한 뒤에도 파일에 실행 권한이 없으면 설치가 시작되지 않습니다. **나오는 오류에 해당하는 단계를 따라 주세요.** 실행용 파일과 삭제용 파일은 각각 따로 처리해야 할 수 있습니다.

<a id="security-blocked"></a>

#### 1. macOS 보안 설정으로 차단될 때

**증상:** 개발자를 확인할 수 없거나 Apple이 악성 소프트웨어 여부를 확인할 수 없다는 안내가 나오며 실행이 차단됩니다. 현재 AnyControl 배포 파일은 서명·공증되지 않아 이러한 안내가 나타날 수 있습니다.

1. 파일을 [공식 GitHub Releases](https://github.com/maboloar/anycontrol/releases)에서 다운로드했는지 확인합니다.
2. Finder에서 해당 `.command`를 더블클릭해 차단 안내를 확인한 뒤 닫습니다.
3. **Apple 메뉴() → 시스템 설정 → 개인정보 보호 및 보안**을 엽니다.
4. 아래로 스크롤해 **보안** 영역에서 해당 파일의 차단 안내 옆 **그래도 열기**를 누릅니다.
5. 확인 창에서 **열기**를 선택하고, 요청되면 Mac 로그인 암호 또는 Touch ID로 인증합니다.

**그래도 열기**가 보이지 않으면 파일을 다시 열어 차단 안내를 띄운 직후 설정을 확인하세요. 학교·회사에서 관리하는 Mac은 관리자 정책에 따라 허용할 수 없는 경우가 있습니다. 자세한 설명은 [Apple의 앱 실행 안내](https://support.apple.com/ko-kr/102445)를 참고하세요.

이후 **“적절한 접근 권한이 없기 때문에…”**라는 다른 오류가 나오면 아래 2단계로 진행합니다.

<a id="execution-permission"></a>

#### 2. “적절한 접근 권한이 없기 때문에…”라고 나올 때

**증상:** 파일을 실행할 접근 권한이 없다는 안내가 나옵니다. 다운로드한 파일에 실행 권한이 빠져 있는 경우 `chmod`로 해당 파일에 실행 권한을 추가합니다.

1. `⌘ + Space`를 누르고 **터미널**(Terminal)을 검색해 엽니다.
2. 터미널에 **`chmod u+x`를 입력한 뒤 공백을 한 칸** 넣습니다. 아직 Enter는 누르지 않습니다.
3. Finder에서 다운로드한 `.command` 파일을 **터미널 창으로 끌어놓습니다**. 파일 경로가 자동으로 입력됩니다.
4. Enter를 누릅니다. 오류 메시지 없이 다음 입력 줄이 나오면 정상입니다.
5. Finder로 돌아가 같은 `.command` 파일을 다시 더블클릭합니다.

예를 들어 파일이 **다운로드** 폴더에 있다면 다음 명령을 그대로 사용할 수 있습니다. 다른 폴더에 있거나 이름이 달라졌다면 위의 끌어놓기 방법을 사용하세요.

```bash
chmod u+x "$HOME/Downloads/AnyControl-v1.8.0-macOS.command"
```

삭제용 파일에서도 같은 오류가 나오면 해당 파일에 별도로 적용합니다.

```bash
chmod u+x "$HOME/Downloads/AnyControl-Uninstall-v1.8.0-macOS.command"
```

이 명령은 **지정한 파일에 현재 사용자의 실행 권한을 추가**합니다. 프로그램을 설치하거나 실행하지 않습니다. 파일을 다시 열었을 때 보안 차단 안내가 나오면 [1단계](#security-blocked)도 완료하세요. Apple 공식 설명은 [파일을 실행 가능하게 만들기](https://support.apple.com/ko-kr/guide/terminal/apdd100908f-06b3-4e63-8a87-32e71241bab4/mac)를 참고하세요.

라이브러리 복구가 필요하면 실행파일이 있는 폴더에서 다음 명령을 실행합니다.

```bash
./AnyControl-v1.8.0-macOS.command --repair
```

해결되지 않으면 [GitHub Issues](https://github.com/maboloar/anycontrol/issues)에 macOS 버전, Mac 모델, 오류 메시지를 남겨 주세요. 로그를 첨부하기 전 사용자 이름이나 개인 경로 등 개인정보를 확인하세요.

### DJ 예시 매핑과 물체 삭제

DJ 셋 위의 **물체 예시 · 자동 매핑**을 누르면 현재 일반 물체 수에 맞춰 실제 케이블을 연결합니다. 1개면 좌우로 믹스, 앞뒤로 볼륨, 기울기로 필터, 들기로 클랩을 조작하고 재생은 화면의 재생 버튼으로 합니다(터치 배정 없음). 2개면 영상 왼쪽부터 A/B 덱을 맡습니다. 각 물체 터치로 해당 덱 재생/정지, 앞뒤로 볼륨을 조작하고, A의 좌우·기울기·들기는 믹스·템포·클랩, B의 기울기·들기는 필터·에코입니다. 3개 이상이면 앞의 2개를 사용합니다. DJ 연결만 교체하며 다른 매핑은 유지합니다.

등록 물체를 삭제하면 해당 물체의 현재 케이블도 즉시 제거됩니다. 저장 프로필은 보존합니다. 카메라는 시작할 때 homese → 17sa → FaceTime HD Camera 순으로 우선 선택하며, 목록에서 다른 장치를 직접 선택할 수 있습니다. 다른 분할 후보를 골라도 같은 물체 ID라 매핑 연결이 유지됩니다. 고급 모드의 성능 지표 옆 **i**에서 측정 범위와 의미를 확인할 수 있습니다.

### 게임패드 채널과 고급 성능

| 게임 | 1P | 2P |
|---|---|---|
| 레이싱 | 왼쪽 스틱 X, RT 가속·LT 브레이크(1인) | 오른쪽 스틱 X |
| Pong | 왼쪽 스틱 Y | 오른쪽 스틱 Y |
| 과일 받기·에어 하키 | 왼쪽 스틱 X/Y | 오른쪽 스틱 X/Y |
| 좀비 서바이벌 | 왼쪽 스틱 X/Y | — |

매핑 패널의 일반 스틱·트리거 잭으로도 같은 채널을 조작합니다. 기존 게임 전용 출력 프로필은 불러올 때 패드 축으로 변환하며, 같은 축의 예전 연결이 여러 개면 뒤에 있는 연결을 사용합니다. 저장 파일은 따로 덮어쓰지 않습니다. 예시 이름은 **(바닥)** / **(영상XY)**이며 후자는 물체의 영상 상하 이동으로 Y를 조작합니다. 가상 패드 계산은 ‘보기만’에서도 작동하고, 실제 OS 마우스·키보드 출력은 기존 출력 설정을 따릅니다.

고급 성능에는 기존 지표와 함께 **캡처 슬롯 교체, 카메라 프레임 누락, 미리보기 디코딩 생략, 미리보기 용량(p50), 처리 프레임 누계, 물체 추적 상태**를 표시합니다. 각 i에서 집계 범위와 의미를 확인하세요. 소스가 제공하지 않는 값은 –로 표시합니다.

### 영상 클릭으로 매핑 연결

1. 물체를 먼저 등록합니다.
2. 매핑 패널의 **기능 잭**에서 케이블을 집거나 **기존 케이블**을 클릭해 고릅니다.
3. 카메라 영상의 등록 물체를 클릭하면 그 물체 카드 잭에 연결됩니다. 기존 케이블을 골랐다면 해당 기능의 물체가 교체됩니다. 실제 선 끝은 계속 **물체 패널**에 표시됩니다.

영상에서 물체를 먼저 클릭하고 기능 잭을 누르는 순서로는 연결되지 않습니다. 영상 클릭은 케이블 시작점이 아닙니다. 맨손은 영상의 손 그림이 아닌 **맨손 카드 잭**으로 연결하세요. 빈 배경·아직 등록하지 않은 물체·추적을 놓친 물체는 연결 대상이 아니며, 케이블을 집은 상태로 배경을 눌러도 새 물체를 등록하지 않습니다. ESC로 취소합니다. 좌우 반전과 작은 실시간 미리보기도 지원하며, 작은 영상의 검은 여백은 제외합니다.

### 실제 OS 입력 표시

**출력 → 실제 (OS 입력)**을 켜면 기존 상단 제목 바 자체가 3초 대기 애니메이션으로 바뀌고, 작동 시 빨간색이 됩니다. 안내와 **정지 (ESC)**는 상단바 가운데에 표시되며, 대기·작동 중에는 아래로 스크롤해도 상단바가 고정됩니다. 별도 배너는 추가하지 않습니다. 정지 버튼이나 ESC는 기존 긴급 정지 경로로 실제 입력과 눌린 출력을 해제합니다. 입력 오류로 정지 요청이 실패하면 작동 표시를 숨기지 않습니다.
