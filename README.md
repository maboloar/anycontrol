# AnyControl v1.8.0

#### 2026 고려대학교 × AWS AI INNOVATORS CHALLENGE 출품작

*카메라 한 대면 충분합니다. 책상 위 컵도, 평범한 펜도, 맨손도 마우스가 되고, 키보드가 되고, 게임패드가 됩니다. 여러 물체를 동시에 알아보고, 가려져도 기억해서 다시 찾아냅니다. 모든 처리는 실시간·온디바이스로 작동해 인터넷 연결 없이도 가능합니다.*

카메라로 물체와 손의 움직임을 추적해 마우스·키보드·게임패드 입력으로 쓰는 macOS용 로컬 웹앱입니다. 물체 매핑, 맨손 마우스, 펜·맨손 그리기와 체험용 게임을 제공합니다.

## 다운로드 및 설치

1. [GitHub Releases](https://github.com/maboloar/anycontrol/releases)에서 `AnyControl-v1.8.0-macOS.command`를 받습니다. 삭제용 `AnyControl-Uninstall-v1.8.0-macOS.command`도 함께 받아 두세요. **Source code 압축 파일은 설치 파일이 아닙니다.**
2. `.command` 파일을 더블클릭합니다. 보안 차단이나 “적절한 접근 권한이 없기 때문에…” 오류가 나오면 [처음 실행 안내](#first-launch-permissions)를 따라 주세요. 최초 설치는 인터넷 속도에 따라 수 분 걸립니다.
3. 카메라 권한을 허용하면 브라우저에서 AnyControl이 자동으로 열립니다.

Python과 필요한 라이브러리는 자동으로 설치되며, 미리 설치할 것은 없습니다. 설치 위치는 `~/Library/Application Support/AnyControl/`이고 저장한 매핑은 `profiles/`에 보관됩니다.

## 요구사항

### 필수 실행 요구사항

- **OS·기기:** macOS 14 이상, Apple Silicon(M1 이상)
- **메모리:** 8GB 이상, 16GB 권장
- **최초 설치:** 디스크 여유 공간 4GB 이상 및 인터넷
- **카메라:** 필수 — iPhone 연속성 카메라 USB 연결 권장
- **권한:** 카메라 필수, 실제 마우스·키보드 제어 시 손쉬운 사용 권한
- **오프라인 실행:** 최초 설치 후 인터넷 없이 사용 가능

### 개발 시 추가 요구사항

- **Python:** 3.12 이상, 3.13 권장
- **Node.js:** 빌드 22.12 이상 / 테스트 22.22.2 이상 또는 24.15 이상

소스 실행·테스트·배포 파일 빌드는 [개발 안내](DEVELOPMENT.md)를 참고하세요.

## iPhone 연결 — 연속성 카메라 (Continuity Camera)

iPhone을 Mac의 웹캠으로 쓰는 Apple 기능입니다. **USB 유선 연결을 권장합니다.** 조건은 Apple의 [연속성 카메라 안내](https://support.apple.com/ko-kr/102546)를 따릅니다.

- iPhone XR 이후, iOS 16 이상. 두 기기가 **이중 인증을 쓰는 같은 Apple 계정**에 로그인되어 있어야 합니다.
- iPhone의 **설정 → 일반 → AirPlay 및 연속성**에서 **연속성 카메라**를 켜고, Wi‑Fi와 Bluetooth를 켭니다.
- USB 연결 시 iPhone에서 **이 컴퓨터를 신뢰**를 누릅니다.

iPhone을 잠근 채 거치대에 고정해 후면 카메라가 책상을 보게 둡니다. 시작할 때 연결된 iPhone이 있으면 자동으로 먼저 선택합니다(부스용 카메라가 있으면 그 카메라가 먼저). 다른 장치는 **카메라 → 장치 새로고침**에서 고를 수 있습니다.

## 종료와 업데이트

**브라우저의 AnyControl 탭을 닫으면 종료됩니다.** 여러 탭을 열었다면 모두 닫으세요. 약 5초 뒤 서버와 터미널 프로그램이 함께 꺼집니다. 다시 쓰려면 같은 `.command`를 더블클릭하고, 업데이트할 때는 새 릴리스의 실행파일을 열면 됩니다. 저장한 프로필은 유지됩니다.

## 삭제

`AnyControl-Uninstall-v1.8.0-macOS.command`를 더블클릭하고 안내를 따릅니다. 저장한 프로필은 지울지 따로 묻습니다(기본 보존). 내려받은 `.command` 파일과 macOS 권한 목록은 남으니 필요하면 직접 정리하세요.

## 외부 구성요소

물체 추적에는 EfficientTAM, 손 인식에는 Apple Vision(기본)과 MediaPipe(선택)를 사용합니다. 출처와 라이선스는 [외부 구성요소 안내](THIRD_PARTY.md)에 있습니다.

## Troubleshooting

| 문제 | 해결 방법 |
|---|---|
| `.command`가 보안 설정으로 차단됨 | [1. macOS 보안 차단 해제](#security-blocked)를 따릅니다. |
| “적절한 접근 권한이 없기 때문에…” | [2. 실행 권한 부여](#execution-permission)를 따른 뒤 다시 더블클릭합니다. |
| 설치가 실패하거나 멈춤 | 인터넷과 여유 공간 4GB를 확인하고 같은 파일을 다시 실행합니다. 로그는 `~/Library/Application Support/AnyControl/logs/`에 있습니다. |
| 브라우저가 열리지 않음 | 터미널에 표시된 주소(기본 `http://127.0.0.1:8767`)를 직접 엽니다. |
| 카메라가 보이지 않거나 화면이 검음 | macOS 카메라 권한을 확인하고, 카메라를 쓰는 다른 앱을 끈 뒤 **장치 새로고침**을 누릅니다. |
| **iPhone 연속성 카메라가 장치 목록에 안 나옴** | **iPhone을 USB 케이블로 Mac에 유선 연결**하고 iPhone에서 **이 컴퓨터를 신뢰**를 누른 뒤 **장치 새로고침**을 누릅니다. 같은 Apple 계정·연속성 카메라 켜짐·Wi‑Fi/Bluetooth도 확인하세요. |
| 실제 마우스·키보드가 움직이지 않음 | **시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용**에서 권한을 허용하고 앱에서 실제 입력을 켭니다. |
| 추적이 흔들리거나 물체를 놓침 | 조명을 밝게 하고 카메라를 고정합니다. 배경과 구분되는 물체를 쓰고, 필요하면 다시 선택합니다. |
| 탭을 닫아도 종료되지 않음 | 다른 AnyControl 탭을 확인하고, 계속 실행 중이면 터미널에서 `Ctrl+C`를 누릅니다. |

### 처음 실행 시: 보안 차단 및 실행 권한

다운로드한 `.command`를 처음 열면 아래 두 오류가 차례대로 나올 수 있습니다. 나오는 오류에 맞는 단계를 따르세요. 실행용·삭제용 파일은 각각 처리해야 할 수 있습니다.

<a id="security-blocked"></a>

#### 1. macOS 보안 설정으로 차단될 때

배포 파일이 서명·공증되지 않아 나타나는 안내입니다.

1. 파일을 [공식 GitHub Releases](https://github.com/maboloar/anycontrol/releases)에서 받았는지 확인합니다.
2. `.command`를 더블클릭해 차단 안내를 확인한 뒤 닫습니다.
3. **Apple 메뉴() → 시스템 설정 → 개인정보 보호 및 보안**에서 **보안** 영역의 **그래도 열기**를 누릅니다.
4. 확인 창에서 **열기**를 누르고 암호나 Touch ID로 인증합니다.

학교·회사에서 관리하는 Mac은 허용되지 않을 수 있습니다. 자세한 내용은 [Apple 안내](https://support.apple.com/ko-kr/102445)를 참고하세요.

<a id="execution-permission"></a>

#### 2. “적절한 접근 권한이 없기 때문에…”라고 나올 때

다운로드한 파일에 실행 권한이 빠진 경우입니다. 터미널에서 해당 파일에만 실행 권한을 추가합니다.

1. `⌘ + Space` → **터미널**을 엽니다.
2. `chmod u+x `(끝에 공백 한 칸)를 입력하고, Finder에서 `.command` 파일을 터미널 창으로 끌어놓은 뒤 Enter를 누릅니다.
3. 같은 `.command`를 다시 더블클릭합니다.

파일이 **다운로드** 폴더에 있다면 다음 명령을 그대로 써도 됩니다.

```bash
chmod u+x "$HOME/Downloads/AnyControl-v1.8.0-macOS.command"
```

라이브러리 복구가 필요하면 실행파일이 있는 폴더에서 다음을 실행합니다.

```bash
./AnyControl-v1.8.0-macOS.command --repair
```

해결되지 않으면 [GitHub Issues](https://github.com/maboloar/anycontrol/issues)에 macOS 버전, Mac 모델, 오류 메시지를 남겨 주세요(로그의 개인정보는 먼저 확인).

## 사용법

- **처음이라면:** 제목 오른쪽 **? 안내**를 누르면 따라 하기 튜토리얼이 열립니다. 물체 등록 → 기능 연결 → 게임 고르기 → 자동 매핑 → 직접 해 보기 순서로, 해낸 단계는 초록색으로 바뀌며 넘어갑니다.
- **물체 등록:** 카메라 영상에서 물체를 드래그합니다. 색이 배경과 구분되는 물체가 좋습니다.
- **기능 연결(매핑):** 물체 카드의 잭을 기능 잭으로 끌거나, 기능 잭을 누른 뒤 영상 속 물체를 누릅니다. 케이블을 누르면 입력 종류·감도·방향을 바꾸고, **매핑 해제**나 케이블 휠 클릭으로 뺍니다. **+ 매핑 추가**로 원하는 키·마우스·게임패드 출력을 직접 만들 수 있습니다. **매핑 전체 초기화**는 두 번 눌러 실행합니다.
- **물체 마우스:** 마우스 패널에서 물체 마우스와 대상을 고릅니다. 좌우 이동 → 커서 좌우, 카메라 쪽/반대쪽 → 커서 위아래이며 **커서 이동만 합니다**(손 추적 없음). 클릭은 물체 잭을 **마우스 클릭** 기능에 연결해 물체를 살짝 들어 하거나, 맨손 마우스를 씁니다.
- **맨손 마우스:** 손바닥 위치로 커서를 움직입니다. 엄지+검지 = 왼쪽 누름·드래그, 엄지+중지 = 오른쪽 누름, 검지·중지만 펴고 위아래 = 스크롤.
- **물체 터치:** 케이블 입력을 **손이 물체에 닿음**으로 고르면 손으로 물체를 덮을 때 버튼처럼 눌립니다. 처음에는 손을 잠깐 떼어 물체의 원래 모습을 잡게 해 주세요. 민감도는 매핑 패널에서 조절합니다.
- **게임:** 레이싱·퐁·에어 하키·과일 받기·좀비 서바이벌은 화면 아래 데모 줄에서 고른 뒤 인원(기본 1인)·컨트롤러·조작법을 정하고 **자동 매핑**을 누릅니다. 시작 전 게임 화면에 고른 조작법이 안내되고, 연결 없이 시작하면 시작하지 않고 자동 매핑을 하라고 알려 줍니다. 큰 시작 버튼이나 `Space`로 시작·일시정지합니다.
- **DJ 셋:** **자동 매핑**을 누르면 지금 연결을 모두 해제하고 DJ 연결만 만듭니다(다른 연결이 있으면 두 번 눌러 확인). 물체 1개면 좌우 = 믹스·앞뒤 = 볼륨·기울기 = 필터·들기 = 클랩, 2개면 영상 왼쪽부터 덱 A/B를 맡고 터치로 재생합니다.
- **보정:** 대상을 고른 뒤 **빠른 자동 보정**에서 잠깐 정지 → 좌우 왕복 → 앞뒤 왕복을 합니다. 중앙으로 되돌아올 필요는 없습니다.
- **실제 Mac 제어:** **출력 → 실제 (OS 입력)**을 켜면 3초 뒤 시작하고 상단바가 빨갛게 바뀝니다. 먼저 가상 데스크톱에서 연습하세요.
- **긴급 정지:** `Esc`로 출력을 멈추고 눌린 키·버튼을 해제합니다.
- **초기화와 전시 기능:** **모든 세팅 초기화**(두 번 누름)는 물체·매핑·설정을 지우고 저장 프로필과 카메라 연결은 남깁니다. 120초 동안 입력이 없으면 시연 영상이 나오며 같은 초기화를 합니다(대기 시간은 고급 모드에서 바꿀 수 있고 초기화해도 유지). 20초 동안 입력이 없으면 상단바에 ‘처음이신가요?’ 문구가 뜨며, ×로 닫거나 튜토리얼을 한 번 열면 다음 시연 화면 전까지 뜨지 않습니다. 고급 모드의 **안내 문구** 체크로 끌 수 있습니다.
- **펜:** 펜 입력과 그리기는 **Beta**입니다. 자동 보정 후 사용하세요.
